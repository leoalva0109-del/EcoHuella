Desarrollo del prototipo

Metodología de desarrollo

El proyecto se construye con aprendizaje supervisado, pruebas de hardware y validación progresiva para llegar a un sistema funcional, medible y presentable.

01

Definición del problema

Se identificaron errores comunes de separación de residuos y se establecieron tres categorías objetivo: orgánicos, reciclables y no reciclables.

02

Construcción del dataset

Se integraron 45,330 imágenes provenientes de datasets públicos como Garbage Classification, RealWaste y Waste Classification Data.

03

Preprocesamiento

Se limpiaron clases ambiguas, se reasignaron etiquetas, se normalizaron imágenes y se aplicó aumento de datos mediante rotación, escalado y recorte.

04

Entrenamiento y fine-tuning

MobileNetV2 se entrenó con transfer learning y ajuste parcial, usando una división 70% entrenamiento, 15% validación y 15% prueba.

05

Integración física

El modelo se integró con cámara, sensores, servomotores, pantalla y lógica de errores para controlar la experiencia completa del usuario.

06

Calibración y seguridad

Se calibran ángulos de servo, umbral de proximidad, tiempos de apertura y cierre, además de topes mecánicos, fusibles y botón de emergencia para proteger al usuario.

Buenas prácticas aplicadas

  • Separación entre captura, clasificación y control físico.
  • Validación de baja confianza antes de accionar compuertas.
  • Pruebas con residuos de uso común y al menos 500 imágenes por clase.
  • Diseño modular para mejorar o reemplazar componentes.
  • Procesamiento local de imágenes para privacidad.

Siguiente etapa

Validación en campo

La evolución natural del prototipo es medir su desempeño con usuarios reales: tiempo de respuesta, tasa de corrección, frecuencia de errores y mejora de hábitos de separación después de varios días de uso.
